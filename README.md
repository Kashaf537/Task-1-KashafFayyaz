# 🤖 Rule-Based Chatbot – Nova AI Assistant

A modern **Rule-Based Chatbot** built using **Python** and **Gradio** with an interactive and visually appealing user interface.  
The chatbot can understand predefined user inputs and respond intelligently with jokes, movie recommendations, food suggestions, motivational quotes, emotional support, and much more.

---

# 📌 Project Overview

Nova AI Assistant is a conversational chatbot that uses **rule-based logic** instead of machine learning.  
It analyzes user input using keywords and conditions, then generates appropriate responses.

The chatbot is designed with:
- 🎨 Modern UI
- 💬 Interactive conversations
- 😊 Emotion-aware responses
- 🎬 Recommendation systems
- 📚 Help menu
- ⚡ Fast response handling

This project is ideal for beginners learning:
- Python programming
- Chatbot development
- Gradio UI development
- Rule-based AI systems
- Frontend styling with CSS

⚙️ How the Chatbot Works

The chatbot uses:

if-else conditions
keyword matching
conversation states

It does not use machine learning.

Example Workflow:
User types a message
Bot checks for matching keywords
Bot selects a response
Response is displayed in the Gradio chat interface
▶️ How to Run the Project
Step 1: Install Python

Make sure Python 3.8 or above is installed.

Download Python from:

https://www.python.org/downloads/

Step 2: Install Required Libraries

Open terminal or command prompt and run:

pip install gradio
Step 3: Save the Python File

Save the chatbot code as:

chatbot.py
Step 4: Run the Application

In terminal, run:

python chatbot.py
Step 5: Open the Chatbot

After running the file, Gradio will generate a local URL like:

http://127.0.0.1:7860

Open it in your browser.
